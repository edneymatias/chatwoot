# Phase 8: List View for the Kanban Board

**Status**: placeholder — pending brainstorm session

## Quick Preview

An alternate, list-based rendering of the same Opportunities data (rows instead of
columns/cards) as a toggle next to the Kanban board, for users who prefer a dense
tabular view over drag-and-drop lanes. Needs design for: which columns the list
shows, whether it supports sorting/filtering beyond what the board offers, whether
stage changes are still possible from the list (e.g. a stage dropdown per row) or
it's read-only, and whether it's a separate route or a view-mode toggle on the same
board route.
